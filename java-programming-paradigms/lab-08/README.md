# Laboratorul 8 — Paradigme de Programare

Acest folder conține exerciții academice realizate în Java în cadrul laboratoarelor universitare. Codul a fost păstrat cât mai aproape de forma originală, pentru a reflecta exercițiile realizate în timpul cursului.

## Conținut

- `Main.java` — fișier sursă Java (`src/Main.java`).
- `Problema2.java` — fișier sursă Java (`src/Problema2.java`).

### Alte fișiere incluse
- `.gitignore`
- `laborator8_input.xlsx`

## Cum se rulează

1. Deschide proiectul sau fișierele sursă într-un IDE compatibil cu Java, de exemplu IntelliJ IDEA.
2. Verifică dacă laboratorul folosește biblioteci externe sau fișiere de intrare.
3. Rulează clasa care conține metoda `main`, dacă exercițiul are un punct de intrare.

Instrucțiunile exacte pot diferi de la un exercițiu la altul.

## Scop

Exercițiile sunt materiale de studiu și practică. Acest repository documentează activitatea academică; nu presupune că toate programele au fost refactorizate sau testate integral.
